# ECSE321 Team 14 Project: GameNight
## Project Overview
This web application connects board game enthusiasts by allowing players and game owners to share their collections, organize events, and borrow games. Users can manage their profiles, browse available board games, leave reviews, and register for events. Game owners can track their lending history and approve borrowing requests, while all users can create and join game sessions.
